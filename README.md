В данном проекте решается задача бинарной классификации для предсказания вероятности клика по рекламному объявлению (показатель CTR) на основе исторических данных рекламных показов и 
взаимодействий пользователей.   

Примечание:  
В текущем публичном репозитории используется демонстрационная часть датасета, поэтому значения метрик, распределения и графики в коде могут отличаться от исходной версии

Стек:
Python, Pandas, Scikit-Learn, Phik, Matplotlib, Seaborn

Установка и запуск:
Клонируйте репозиторий:
git clone <ссылка-на-репозиторий>
cd <название-папки-проекта>

Установите необходимые зависимости:
pip install -r requirements.txt

Запустите Jupyter Notebook для просмотра пошагового хода исследования:
jupyter notebook
